Screens

Screens are responsible for displaying information and processing user actions. Each screen has a query() method and a layout() method.

A screen describes the data and layout of a page.

public function query(): array
{
    return ['name' => 'Orchid'];
}

Screen methods

MethodPurpose
query()Prepare the data.
layout()Define the page layout.
